# Автоматизированная система учета и управления для мороженого завода

Проект реализует базовый прототип ИС для производственного предприятия (мороженый завод): учет продукции, сырья, производства, продаж, отчетности и аналитики.

## 1) Анализ деятельности и ключевые бизнес-процессы

Выделены следующие процессы:

1. **Закупка сырья**
   - регистрация поставщиков;
   - оформление поставок сырья;
   - контроль остатков и порогов дозакупки.

2. **Производство**
   - хранение рецептур (норм расхода сырья на единицу продукции);
   - выпуск производственных партий;
   - автоматическое списание сырья.

3. **Склад готовой продукции**
   - учет остатков по видам мороженого;
   - контроль движения запасов (поступление после производства и списание после продаж).

4. **Продажи**
   - фиксация реализаций по каналам;
   - расчет выручки и валовой прибыли.

5. **Отчетность и аналитика**
   - отчет по складу готовой продукции;
   - аналитика продаж (объем, выручка, себестоимость, прибыль);
   - контроль дефицита сырья.

## 2) Требования к информационной системе

### Функциональные
- Ведение справочника продукции и сырья.
- Хранение рецептур для каждой позиции продукции.
- Регистрация производственных партий.
- Регистрация продаж.
- Формирование управленческих отчетов.

### Нефункциональные
- Простота развертывания (SQLite, Python stdlib).
- Целостность данных (внешние ключи, проверки CHECK).
- Расширяемость (разделение слоя БД и бизнес-логики).

## 3) Структура базы данных

Реализованы таблицы:
- `products`, `inventory` — продукция и остатки;
- `raw_materials`, `suppliers`, `purchase_orders` — сырье и закупки;
- `recipes` — рецептуры;
- `production_batches` — производственные партии;
- `sales` — продажи.

SQL-схема создается в `src/db.py` функцией `init_db`.

## 4) Проектирование автоматизированной системы

Архитектура:
- `src/db.py` — подключение и инициализация схемы БД.
- `src/system.py` — доменная логика системы (`FactorySystem`):
  - создание справочников;
  - операции производства и продаж;
  - получение отчетов.
- `tests/test_system.py` — автотесты ключевых сценариев.

## 5) Реализованные функции ввода, хранения и обработки данных

Класс `FactorySystem` предоставляет:
- `bootstrap()` — подготовка БД;
- `add_product()`, `add_raw_material()`, `set_recipe()` — ввод справочных данных;
- `produce()` — выпуск продукции с проверкой/списанием сырья;
- `sell()` — продажа с проверкой остатков.

## 6) Отчеты и аналитика

Реализованы методы:
- `inventory_report()` — текущие остатки готовой продукции;
- `sales_analytics()` — агрегат по продажам и прибыли;
- `low_materials_report()` — сырье ниже порога пополнения.

## 7) Тестирование и оценка эффективности

Покрыты автотестами сценарии:
- полный цикл «ввод справочников → производство → продажа → отчеты»;
- контроль дефицита сырья.

Запуск:

```bash
python -m unittest discover -s tests -v
```

## Быстрый старт

```python
from src import FactorySystem

system = FactorySystem("icecream_factory.db")
system.bootstrap()

pid = system.add_product("Эскимо", "шоколадное", 90.0, 150.0, unit="кг")
cream = system.add_raw_material("Сливки", "л", 200.0, 30.0)
sugar = system.add_raw_material("Сахар", "кг", 100.0, 20.0)

system.set_recipe(pid, [(cream, 1.2), (sugar, 0.3)])
system.produce(pid, 10.0)
system.sell(pid, 4.0, "Опт")

print([dict(row) for row in system.inventory_report()])
print([dict(row) for row in system.sales_analytics()])
```
