# IceFactory

Репозиторий содержит стартовые артефакты для ИС **«Автоматизация деятельности мороженого завода»**:

- проектная техническая спецификация: `docs/technical-spec.md`;
- PostgreSQL-схема данных: `db/schema.sql`.

## Быстрый старт (БД)

1. Создайте БД `icefactory` в PostgreSQL.
2. Примените схему:

```bash
psql -d icefactory -f db/schema.sql
```

3. Проверьте, что созданы таблицы, представления и триггеры.

## Основные возможности схемы

- справочники (сырье, продукция, клиенты, поставщики, единицы);
- пользователи и роли;
- учет движений сырья и готовой продукции;
- рецептуры и состав;
- производственные партии и история статусов;
- контроль качества (ОТК) с автоблокировкой партии;
- заказы, отгрузки, складские списания;
- представления остатков на складе.
